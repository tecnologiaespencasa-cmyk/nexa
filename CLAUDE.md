# Instrucciones del proyecto

## Diseño de interfaces (frontend-design)

Cuando se cree una vista/página nueva o se rediseñe una existente (Razor views, CSS, HTML, layout, componentes visuales), invoca primero el skill `frontend-design` (`.claude/skills/frontend-design/SKILL.md`) antes de escribir el marcado o los estilos. Úsalo por defecto para cualquier tarea de UI/UX de este proyecto: dashboards, formularios de censo, reportes, paneles de "Mi espacio corporativo", etc. No es necesario para cambios puramente de backend/lógica sin impacto visual.
